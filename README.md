# 智启陪读 WiseMuse

> **Slogan：智启灵感，伴读成长**

一款面向儿童的**学习助手**安卓 App：拍下或导入 PDF 教材，识别文字后进行
**朗读、跟读验证、听写与生词复习**，帮助孩子巩固课堂所学。

## 功能

- 📷 **教材导入**：拍照 / 相册选图 / 导入 PDF、Word、TXT 教材
- 🔍 **文字识别**：电子版 PDF 文本层提取 + 扫描件 ML Kit OCR（离线 Bundled，无需 GMS）
- 🔊 **朗读**：系统 TTS，儿童向语速、逐句 / 逐词、循环跟读
- 🎤 **跟读验证**：离线 Vosk 语音识别 + 模糊评分，孩子读完即知读得对不对
- ✍️ **听写**：中文听音选字 / 英文拼写 / 语音跟读式三种形态
- 📚 **生词本**：学习过程中标记未掌握词语，自动复习、统计掌握率
- 🤖 **AI 助教（规划中）**：讲词、答疑、基于错词出题

## 技术栈

- Flutter 3.29.3 / Dart
- `flutter_tts`（朗读）、`google_mlkit_*`（离线 OCR/翻译，Bundled 无 GMS）
- Vosk（离线语音识别，跟读验证）
- `sqflite`（生词本与学习记录）、自研 PDFBox 文本坐标提取与 PDF 渲染

## 构建

APK 由 GitHub Actions 云端构建，在 Releases 页面下载最新安装包。

## 目录结构

```
lib/
  app/          应用壳与主题
  core/         领域模型、存储、设置
  services/     引擎层（TTS/OCR/PDF/ASR/评分）
  features/     功能模块（导入/阅读/跟读/听写/生词本/助教）
  widgets/      共享组件
  vendor/       vendored 依赖
```
