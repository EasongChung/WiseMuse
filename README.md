# 智启陪读 WiseMuse

> **Slogan：智启灵感，伴读成长**

一款面向儿童的**学习助手**安卓 App：拍下或导入教材，经识别、朗读、跟读验证、
听写、生词复习到章节测验，形成「导入 → 学习 → 测验 → 巩固」的完整闭环，
帮助孩子巩固课堂所学。数据仅存本机，核心链路离线可用。

---

## 功能总览 🧸

### 📥 教材导入
- 四种来源：拍照 / 相册选图 / PDF / Word / TXT
- 后台流式导入，应用切回前台自动恢复中断任务
- 知识提取**单页失败不中断整本任务**，支持页级检查点断点续传

### 🔍 文字识别
- **电子版 PDF**：PDFBox 字符坐标提取，支持逐字精确定位点击朗读
- **扫描件 / 图片**：ML Kit 离线 OCR（中文 Bundled 模式，无需 Google 服务，国产机可用）
- **翻译引擎**：三级自动回落（ML Kit → 本地大模型 → 云端 API），支持中 / 英 / 日 / 韩 / 法 / 德 / 西 / 葡 8 语种互译与离线模型下载管理

### 📖 阅读
- 四种阅读模式按来源自动切换：**PDF 原文 / 图片 / Word / TXT**
- 点击句子即朗读并高亮；支持连续朗读、连读暂停、目录导航、长文虚拟分页
- 原文与译文对照讲解；基于当前句上下文直接发起「问 AI」

### 🔊 智能朗读
- 系统 TTS 儿童向语速，支持逐句 / 逐词 / 循环 / 连读暂停
- 真实 Android 系统音色自动发现与选择
- **云端大模型 TTS 混合引擎**：独立供应商管理，获取并持久化可用模型 / 音色，按「供应商 + 模型」分组隔离

### 🎤 跟读验证
- **离线 Vosk ASR** + 跟读评分引擎（编辑距离 DP 回溯 + 拼音去声调音近容错，五态逐字对齐）
- 全屏大字拼音卡片、慢速领读、彩色声波动画、逐字正误高亮与关卡式流转
- 双模式：ASR 评分 / 听写自评；Vosk 未就绪时自动回落自评

### ✍️ 听写
三模式自由切换：
- **听音选字**：听读音 4 选 1，即时对错反馈
- **朗读列表**：全屏展示词语自动朗读，供跟读记忆
- **拼字积木**：听句子后点击词语卡片按正确顺序排列

### 📚 生词本
- 学习过程中自动沉淀未掌握词语，标记掌握状态
- **艾宾浩斯间隔复习**：卡片 / 选择 / 拼写三形态
- 掌握率统计与错词分布可视化

### 🏆 章节测验
三阶分级题型体系：
- ⭐ **基础认读**：朗读评分 + 听音选字
- ⭐⭐ **词句理解**：词句释义选择
- ⭐⭐⭐ **拓展应用**：AI 生成情境选择题
- 1–5 星评分；朗读题复用 Vosk + 跟读评分双模式；错题专项强化池

### 🧠 内置知识库
- 幼小衔接（声母 / 韵母 / 整体认读 / 字母 / 基础识字）
- 一 ~ 二年级语数英核心知识点，共 222+ 条种子（三 ~ 六年级预留扩展）
- 年级分级筛选；知识点查看 / 编辑 / 管理；内置书自动生成句子数据，可浏览可索引

### 🤖 AI 智能助教
- 启发式结构化多维讲解（讲词、释义、造句、拓展）
- 变式练习挑战：针对薄弱词生成巩固选择题
- 今日推荐复习：融合知识库掌握度与错词频次智能推荐

### 💬 问 AI
- 多会话有序上下文管理，会话 Scope 隔离
- 关联当前阅读书籍；**RAG 知识库问答**（向量索引，每书独立构建 / 重建 / 清理）
- 支持语音输入与 TTS 朗读回答，Markdown 渲染

### 📊 学习统计
- 掌握率 / 学习记录 / 错词分布 / 近期活动 / 测验深度统计

### ⚙️ 设置
- AI 供应商管理（云端 OpenAI 兼容 + 本地 llama.cpp 双引擎，按策略自动回落）
- 云端 TTS 独立供应商与模型 / 音色管理
- 翻译引擎选择与语种模型下载管理
- Vosk 语音识别模型管理、朗读参数、运行日志查看 / 导出

## 技术栈

- **Flutter 3.44.9 / Dart 3.12**（Android arm64-v8a，minSdk 26）
- **大模型双引擎**：本地 llama.cpp（Java 桥 vendoring 自官方 `llama.android`，CPU 静态注册 + OpenCL GPU 加速，无 OpenCL 自动回落）+ 云端 OpenAI 兼容 API
- **文字识别**：ML Kit OCR / 翻译 / 语种识别（Bundled，无 GMS 依赖）
- **语音识别**：Vosk（离线，跟读评分与朗读测验）
- **PDF**：自研 PDFBox 文本坐标提取 + `android-pdf-viewer` 原生渲染
- **TTS**：系统真实音色 + 云端大模型 TTS 混合引擎（原生 TtsBridge 状态机串行调度）
- **数据层**：sqflite（生词本、学习记录、知识库、会话，多版本迁移）
- **其他**：`xml`（docx 解析）、`webview_flutter`（Word 原文模式）、`pinyin`（音近评分）、`archive`（模型解压）
- **UI**：「暖色书房」主题（羊皮纸米底 + 墨青文字 + 亮橙 CTA，站酷快乐体标题打包离线）

## 构建

APK 由 **GitHub Actions 云端构建**（本机不执行编译），在 Releases 页面下载最新安装包。
本地仅支持 `dart format` / `flutter analyze` / `flutter test` 静态检查与测试。

## 离线与隐私

- 朗读 / 跟读 / 听写核心链路**离线可用**；在线 API 仅用于 AI 助教、云端 TTS 与在线翻译兜底
- 学习数据（生词、记录、知识库）**仅存本机 sqflite，不上传**
- ML Kit 采用 Bundled 模式，无 Google 服务依赖，国产设备可用
